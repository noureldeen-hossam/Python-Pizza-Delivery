# 🍕 Python Pizza Delivery

A simple Python program that calculates the final price of a pizza based on the customer's choices.

## 🚀 Features

* 🍕 Choose pizza size: Small, Medium, or Large
* 🥓 Add pepperoni
* 🧀 Add extra cheese
* 💰 Automatically calculate the final bill

## 🛠️ Built With

* 🐍 Python
* `input()`
* Variables
* `if / elif / else`
* Nested conditions
* Arithmetic operations
* f-strings

## 📌 Example

```text
Welcome to Python Pizza Deliveries!
What size pizza do you want? S, M or L: M
Do you want pepperoni on your pizza? Y or N: Y
Do you want extra cheese? Y or N: Y

Your final bill is: $24.
```
